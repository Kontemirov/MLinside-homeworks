# A/B Testing Simulation

Симуляционное исследование статистических методов для A/B тестирования.  
Оценка корректности p-value и сравнение мощности критериев.  

### Цель работы  
Смоделировать A/B-эксперимент на синтетических данных и проверить корректность распределения p-value при отсутствии эффекта,
сравнить мощность различных статистических методов,
исследовать влияние ковариат на мощность теста.
### Генерация данных  
Генерируется синтетическая выборка пользователей  
Разбиение на группы A/B через hashing + bucketization  
Контроль и тест коррелированы  
В тестовую группу добавляется искусственный эффект  
### Методы сравнения  
В работе были протестированы:  
- t-test  
- Wilcoxon test  
- Линейная регрессия  
- Линейная регрессия с ковариатой из контроля (CUPED-подход)  
- Множественная регрессия  
- Неправильная регрессия (обучение на тесте — для демонстрации смещения)  
### Проверка корректности (A/A тест)  
Проверено:  
p-value при отсутствии эффекта распределены равномерно  
доля ложных срабатываний соответствует уровню значимости  
Вывод: реализация тестов корректна.  
### Сравнение мощности  
Мощность оценивалась для различных величин эффекта.  
Результаты:  
Линейная регрессия с ковариатой  
Power при 20% эффекте ≈ 0.73  
Множественная регрессия  
Power при 20% эффекте ≈ 0.74  
### Основные выводы  
Добавление ковариаты увеличивает мощность теста.  
Множественная регрессия показывает наилучший результат.  
Неправильное использование данных приводит к смещению p-value.  
CUPED-подход снижает дисперсию и повышает чувствительность теста.  
### Что демонстрирует работа  
понимание распределения p-value  
понимание типа I ошибки  
расчёт статистической мощности  
симуляционное моделирование экспериментов  
корректное применение регрессии в A/B тестировании
