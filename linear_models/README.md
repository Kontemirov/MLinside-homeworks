
# Линейные модели: регрессия и классификация  
В данном разделе представлены два домашних задания из курса ML Inside, посвящённых базовым линейным моделям:  
linear_classification.ipynb — линейные модели для задачи классификации  
linear_regression.ipynb — линейные модели для задачи регрессии  
Основная цель работ — понять математику линейных моделей, реализовать их обучение, изучить влияние признаков и оценить качество предсказаний.  
### Что изучалось  
В рамках этих работ были подробно разобраны:  
- линейная регрессия
- логистическая регрессия
- интерпретация коэффициентов модели
- переобучение и обобщающая способность
- метрики качества для разных типов задач

### Цель

### Что было сделано  
Подготовка и анализ данных  
Обучение модели логистической регрессии  
Получение вероятностей принадлежности к классу  
Анализ влияния признаков через коэффициенты модели  
Оценка качества классификации  
### Освоенные концепции  
сигмоида и вероятностная интерпретация модели  
разделяющая гиперплоскость  
роль коэффициентов в принятии решения  
зависимость качества от признаков  
## Задача 2 — Линейная регрессия

### Что было сделано  
Подготовка данных  
Обучение линейной регрессии  
Анализ коэффициентов модели  
Оценка качества предсказаний на выборке  
### Освоенные концепции  
линейная зависимость между признаками и целевой переменной  
интерпретация весов модели
