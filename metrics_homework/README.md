# Метрики качества моделей  
В данной папке представлено домашнее задание из курса ML Inside, посвящённое глубокому пониманию метрик качества в задачах регрессии и их свойств.  
Файл:
metrics_homework.ipynb — реализация и анализ различных метрик  
Работа направлена на формирование интуиции о том, какие значения предсказаний оптимальны для разных функций потерь и как метрики ведут себя на больших выборах.  
### Цель работы  
Понять, какие константные предсказания оптимальны для разных метрик  
Исследовать поведение метрик на больших данных  
Реализовать собственные функции расчёта метрик  
Разобраться в ранговых метриках для регрессии  
### Реализованные задачи  
1. Оптимальные константы для метрик  
На синтетических данных (gamma-распределение) найдены значения константных предсказаний, минимизирующие: 
MSE → среднее значение  
MAE → медиана  
MAPE → взвешенная медиана    
Реализована собственная функция:  
weighted_median() — вычисление взвешенной медианы через сортировку и накопление весов  
Это демонстрирует фундаментальное свойство функций потерь: разные метрики оптимизируются разными статистиками распределения.  
2. Анализ на больших выборка  
Проведено повторное моделирование на значительно большем объёме данных.  
Показано, что при росте размера выборки:
оценки стабилизируются
значения метрик сходятся к теоретическим
снижается влияние случайных флуктуаций  
3. Реализация regression ROC-AUC  
Реализована собственная метрика рангового качества для регрессии:  
сравнение всех пар объектов  
подсчёт доли правильно упорядоченных пар  
Функция:
regression_roc_auc(pred, target)  
Метрика показывает, насколько хорошо модель сохраняет относительный порядок значений.  
4. Оптимизация для больших данных  
Так как полный перебор пар имеет сложность O(n²), реализована ускоренная версия:
fast_regression_roc_auc()
вычисление по подвыборке (sampling)  
Это позволило применять метрику на очень больших массивах данных.
