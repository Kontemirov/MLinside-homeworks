# Нейронные сети — борьба с затуханием 
градиентов

В данной работе исследуется одна из ключевых проблем глубоких нейронных сетей — затухание градиентов (vanishing gradients). На синтетическом датасете проводится серия экспериментов с глубокой полносвязной сетью и различными методами стабилизации обучения.

## Цель работы

- Понять природу затухания градиентов
- Проанализировать влияние функций активации на обучение
- Проверить практические методы борьбы с затуханием градиента
- Сравнить эффективность различных подходов

## Данные

Используется синтетический датасет для задачи бинарной классификации:

- 200 000 объектов
- 30 признаков (часть из них — шумовые/избыточные)
- Генерация: sklearn.make_classification

Данные делятся на train/test и подаются в сеть батчами.

## Исследуемая архитектура

Была реализована глубокая полносвязная сеть:

- 10 слоев
- Постепенно уменьшающаяся размерность скрытых слоев
- Выход — сигмоида
- Функция потерь: BCELoss
- Оптимизатор: SGD

Дополнительно визуализируется структура сети с помощью torchview.

## Часть 1. Анализ функций активации

Перед экспериментами построены графики:

- Сигмоида и её производная
- Tanh и её производная

Показано, что:
- В насыщенных областях производные близки к нулю
- Это приводит к исчезновению градиентов при backpropagation

## Часть 2. Демонстрация затухания градиентов

Обучение глубокой сети с сигмоидой показало:

- Чем дальше слой от выхода, тем меньше нормы градиентов
- Самые ранние слои почти не обновляются

Это классический пример vanishing gradient.

## Часть 3. Смена функции активации

Проверены варианты:

- Sigmoid
- Tanh
- ReLU

Результат:
- Tanh немного улучшает ситуацию
- ReLU не устраняет проблему полностью в данной архитектуре

## Часть 4. Методы борьбы с затуханием градиентов

Были реализованы и протестированы следующие подходы:

### 1) LeakyReLU
- Позволяет градиенту проходить даже для отрицательных значений
- Даёт более стабильные нормы градиентов

### 2) Batch Normalization
- Нормализация на каждом слое
- Существенно улучшает распространение градиента

### 3) Gradient Clipping
- Принудительное увеличение слишком маленьких градиентов
- Стабилизирует обучение

### 4) Learning Rate Scheduler
- Постепенное уменьшение шага обучения
- Помогает стабилизировать процесс оптимизации

## Итоговый вывод

Наилучший результат показал:

Batch Normalization

Он:
- Значительно уменьшает затухание градиентов
- Делает обучение глубокой сети более стабильным
- Улучшает передачу сигналов между слоями
