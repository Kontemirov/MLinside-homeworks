
## Домашние задания по основам программирования (programming_basics_homework)  

В этой папке собраны домашние задания по основам программирования, которые формируют фундамент для дальнейшего изучения анализа данных и машинного обучения.  
Работы охватывают базовый Python, структуры данных, работу с pandas, алгоритмы, оценку сложности и основы объектно-ориентированного программирования.

### Содержимое  
python_pandas_homework.ipynb — базовый Python и работа с данными в pandas  
algorithms_oop_homework.ipynb — алгоритмы, оценка сложности и основы ООП  
### Цель работы  
Сформировать прочную базу программирования перед переходом к анализу данных и машинному обучению: освоить Python, структуры данных, алгоритмы, оценку сложности и основы ООП.

### Что реализовано  

Python (база)  
- работа со строками, списками и словарями
- циклы и условия
- функции
- рекурсия (Фибоначчи и др.)
- работа со временем и датами
- сортировки с key
- использование map и filter
- задачи на логику и обработку данных  
  
Pandas и анализ данных  
- загрузка CSV-файлов
- первичный анализ данных (EDA)
- группировки и агрегации
- обработка пропусков
- value_counts, фильтрации
- работа с датами
- визуализация
- анализ нескольких датасетов (students, sleep, laptops)  

Алгоритмы  
- линейный поиск
- бинарный поиск
- поиск последовательностей
- подсчёт символов во вложенных структурах
- анализ временной сложности: O(1), O(n), O(n²), O(log n)
- анализ пространственной сложности  

Рекурсия vs циклы  
- сравнение подходов
- примеры вычисления факториала
- разбор преимуществ и недостатков
- понимание стека вызовов  

Основы ООП  
- создание классов
- работа с атрибутами и методами
- инкапсуляция логики в объекты  

Полученные навыки  
- уверенное владение базовым Python
- понимание структур данных
- умение анализировать алгоритмы
- понимание оценки сложности
- навыки работы с pandas
- написание читаемого и структурированного кода
