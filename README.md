# MLinside-homeworks

## О репозитории  
Данный репозиторий содержит мои домашние задания, выполненные в рамках курса по машинному обучению MLinside (курс от Виктора Кантора).   
Работы охватывают ключевые этапы подготовки специалиста по Data Science: от основ программирования и математики до построения моделей и оценки их качества.  
Все задания выполнены в формате Jupyter Notebook и сопровождаются краткими описаниями в локальных README внутри соответствующих папок.  
  
---
  
## Цель репозитория

- Систематизировать учебные проекты по машинному обучению  
- Продемонстрировать практические навыки работы с данными и моделями  
- Показать процесс обучения: от базовых тем к более сложным  
- Использовать репозиторий как портфолио начинающего специалиста  
   
---
  
## Структура репозитория

### programming_basics_homework  

Основы программирования на Python.
    
Содержит:  

- работа с Python и pandas
- основы алгоритмов
- оценка сложности алгоритмов
- базовые принципы ООП
  
Фокус:  

- формирование фундаментальных навыков программирования
- работа со структурами данных
- написание чистого и понятного кода
  
---
  
### linear_model_homework  

Линейные модели для задач регрессии и классификации.  
  
Содержит:  

- логистическая регрессия
- линейная регрессия
- обучение и оценка моделей
- работа с признаками
  
Фокус:  

- понимание базовых ML-алгоритмов
- интерпретируемые модели
- связь математики и практики
  
---
  
### trees_and_ensembles_homework  
  
Деревья решений и ансамблевые методы.  
  
Содержит:  
  
- решающие деревья
- ансамбли деревьев
- градиентный бустинг
- анализ мультиколлинеарности
  
Фокус:  
  
- работа с нелинейными моделями
- понимание принципов ансамблей
- улучшение качества предсказаний
  
---
  
### neural_networks_homework  
  
Введение в нейронные сети.  
  
Содержит:  
  
- анализ функций активации и их производных
- исследование проблемы затухания градиента
- эксперименты с архитектурой глубоких сетей
- сравнение методов борьбы с затухающими градиентами:
  - Batch Normalization
  - LeakyReLU
  - Gradient Clipping
  - изменение learning rate
  
Фокус:  
  
- понимание внутренней механики обучения нейросетей
- практическая работа с PyTorch
  
---
  
### metrics_homework  
  
Метрики качества моделей.  
  
Содержит:  
  
- анализ оптимальных констант для: MSE, MAE, MAPE
- реализацию взвешенной медианы
- реализацию ROC-AUC для регрессии
- оптимизацию вычислений для больших выборок
  
Фокус:  
  
- глубокое понимание метрик
- связь метрики и оптимизируемой функции
  
---
  
### AB_testing_homework  
  
A/B-тестирование и статистический анализ.  
  
Содержит:  
  
- генерацию данных
- проверку статистических гипотез
- сравнение методов
- анализ мощности тестов
  
Фокус:  
  
- применение статистики в продуктовых задачах
- корректная интерпретация результатов экспериментов
